🧮 CalcPro – Smart & Simple Calculator

CalcPro is a modern, responsive calculator web application built using HTML, CSS, and JavaScript. It provides a clean interface with interactive calculator functions, calculation history, keyboard support, and a responsive design.

✨ Features

- ➕ Addition, subtraction, multiplication and division
- % Modulo / percentage operation
- ⌫ Backspace functionality
- 🔄 Positive / negative number toggle
- 📋 Copy result to clipboard
- 🕐 Recent calculation history
- 💾 Calculation history using Local Storage
- 🗑️ Clear calculation history
- ⌨️ Keyboard support
- ⚠️ Error handling for invalid calculations and division by zero
- 🔔 Toast notifications
- 📱 Responsive design
- 🎨 Modern dark-themed user interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- Local Storage API
- Clipboard API

📂 Project Structure

CalcPro/

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Start using the calculator.
